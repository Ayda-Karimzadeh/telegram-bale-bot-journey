# Telegram & Bale Bot Journey

This repository documents my learning journey in building messaging bots using Python.

I use the same bot logic for both **Telegram** and **Bale**.  
The only difference between the two platforms is the API base URL.

## Platform Difference

For Bale bots, the API URL is configured as:
```python
telebot.apihelper.API_URL = "https://tapi.bale.ai/bot{0}/{1}"
```
Other than that, the bot structure and logic remain the same.

## Purpose

- Practice bot development
- Experiment with features step by step
- Track my progress with regular commits
- Build from simple exercises to more advanced implementations

## Technologies

- Python
- pyTelegramBotAPI (telebot)
- Telegram Bot API
- Bale Bot API
